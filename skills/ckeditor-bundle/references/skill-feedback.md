# Reporting feedback on this skill

The maintainers improve this skill over time. Open an issue in these cases:

- The guidance of the skill is wrong, or it is different from what worked.
- A rule is out of date and does not match how Cloud Services or the editor works now.
- Something important is missing, for example a framework, a bundler, a kind of custom plugin, or an upload error.
- You found a fix that the docs do not explain.
- A Cloud Services guide is wrong or incomplete. Name the page and the section.

## Where to report

Open an issue in <https://github.com/ckeditor/skills>. Use the skill feedback template.

## What to include

Keep the report short and specific:

- The setup: the framework, the bundler of the application and of the bundle, the CKEditor 5 version, the installation method, and the premium features.
- The kind of the custom plugin that caused the problem, if any. Do not paste private code.
- What the skill said and what happened. If there was an error, include the exact error code or message, without credentials.
- The fix or the workaround, if you found one.
- The agent or the tool that you use.

## What not to report here

- Report bugs in CKEditor 5 to `ckeditor/ckeditor5`, or to the repository of the related integration.
- Send questions about Cloud Services environments, accounts, licenses, or billing to the Customer Portal and to CKEditor support.

Do not open an issue without the user's knowledge. An issue is public. Show the user what you want to report, and let them confirm it first.
