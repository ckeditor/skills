Introduced the Agent Skills Discovery artifacts in the release process.

Preparing a release now builds a `.tar.gz` archive per skill and an `index.json` manifest following the [Agent Skills Discovery specification](https://github.com/cloudflare/agent-skills-discovery-rfc) into the `release/` directory. Once they are published on `ckeditor.com/.well-known/agent-skills/`, `npx skills add https://ckeditor.com` will install the skills.
