Introduced the Agent Skills Discovery artifacts in the release process.

Preparing a release now builds a `.tar.gz` archive per skill and an `index.json` manifest following the [Agent Skills Discovery specification](https://github.com/cloudflare/agent-skills-discovery-rfc) into the `release/` directory, ready to be served from `ckeditor.com/.well-known/agent-skills/` so that `npx skills add https://ckeditor.com` can install the skills.
