The `ckeditor-update` skill now checks that the project's custom styles still work after the update. It compares every `--ck-*` variable that the project sets or reads and every `.ck-*` selector that it styles with the editor CSS of the old and the new version. When a browser is available, it also compares the computed styles of both versions on a test page. Before, an override that the new editor CSS no longer reads went unnoticed when the update guides did not name the change.
