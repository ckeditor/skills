The `ckeditor-bundle` skill now also sets up the upload of the editor bundle to CKEditor Cloud Services. It adds an upload script that sends the signed `POST /editors` request, and three scripts in `package.json`: `build:bundle`, `upload:bundle`, and `release:bundle`.

The upload script reads the shared configuration, the bundle version, and the test data that the skill prepares, so that the application and the bundle keep one editor definition. It reads the credentials from environment variables, and it exits with an error when the upload fails. As a result, CI can build and check the bundle on each change, and upload the bundle in a release job.
