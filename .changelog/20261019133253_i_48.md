The `ckeditor` and `ckeditor-update` skills now also tag documentation requests with the `utm_content` query parameter, which names the skill: `utm_content=ckeditor` or `utm_content=ckeditor-update`. As a result, the docs access logs can show the requests of each skill and of all skills together.
